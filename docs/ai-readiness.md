## 官网改动

- 新增 `/library` 资料中心及首页入口，采用品牌青绿色、渐变与柔和底纹，支持电脑和手机阅读。
- 新增品牌、联系、FAQ、服务条款与三类养护资料页；原隐私入口永久重定向到 `/privacy`。
- 将已发布的产品和服务生成独立详情、可读路径、正文内链和规范地址。草稿从详情、目录及站点地图同步移除。
- 增加品牌、网站、文章、产品、服务、FAQ 与面包屑 JSON-LD；配置 Canonical、Open Graph、标题与摘要。
- 新增按需求选择清单、服务方案对比、居家步骤指南与六项服务参考价格资料报告。保留真实来源、时间、单位及限制，不编造机构排名、疗效、经营数据或官方社交账号。
- 自动生成 `/sitemap.xml`、`/llms.txt` 与 robots 站点地图声明，管理页设置 `noindex, nofollow`；私有资料和接口不列入目录。
- 支持设置 `PUBLIC_ORIGIN` 统一发布域名，并提供可选的 Node HTTPS 证书配置。原 Nginx 示例保持 HTTP 到 HTTPS 重定向。

## 复测方式与范围

```bash
npm run audit:readiness
npm test
npm run test:readiness-pages
```

检测器默认拒绝私有网络。本地验证只替换抓取适配器，限制访问指定回环主机和端口，读取真实页面和真实 TLS 响应，继续使用原 URL 发现、抽样和评分函数。临时证书仅由验证子进程信任，结束后删除；没有关闭证书校验或修改系统信任。

本次没有部署到公网，100/100 是本地 HTTPS 版本的检测结果。`http://127.0.0.1:4173` 用于开发预览，纯 HTTP 验证为 99/100。公网使用正式域名和有效证书，设置一致的 `PUBLIC_ORIGIN` 与代理协议后，应再次运行：

```bash
READINESS_REQUIRE_FULL=1 node scripts/audit-readiness.mjs https://www.bosye.com/ test-results/ai-readiness-public.json
```

实际域名或检测项目路径不同时，分别替换网址与 `READINESS_EVALUATOR_DIR`。内容、后台发布状态、域名、证书或检测规则改变后，得分需重新验证。
