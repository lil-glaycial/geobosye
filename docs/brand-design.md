# 青绿色品牌设计体系

正式标识：旧官网 `http://www.bosye.com/images/logo.png`。保留原图比例，不重绘或改变颜色。

| 用途                   | 色值      |
| ---------------------- | --------- |
| 品牌青绿、主要按钮     | `#5DBEB9` |
| 更明亮的青绿装饰       | `#4BE0D7` |
| 高对比度青绿文字、链接 | `#006F6A` |
| 主要文字               | `#163D40` |
| 正文辅助文字           | `#4E696B` |
| 浅色背景               | `#EFF8F6` |
| 基础背景               | `#FFFFFF` |

使用 PingFang SC / Microsoft YaHei / 系统无衬线字体；英文数字使用 Arial / Helvetica。最大内容宽度 1280px，桌面两侧留白，平板与手机按断点缩小间距。标题、段落、卡片与按钮采用一致字号与间距。主色按钮配深青文字，浅色文字使用较深青绿保证可读性。

各区块采用与内容对应的背景衬托：品牌与首屏使用发丝曲线，养护与产品使用植物线稿，科研使用细网格和几何连接线，门店使用空间弧线，加盟与培训组合浅青渐变与局部线稿。卡片、价格、资质、门店查询和咨询表单通过浅色渐变、细边框与柔和阴影形成前后层次。四张装饰 SVG 保存在 `assets/decor-*.svg`，属于新页面的矢量装饰，不代表品牌科研或效果图。手机端调整装饰尺寸与位置，背景保持静态，不增加外部请求或动画。

首页的信息顺序为品牌体验、品牌与创始人、服务、科研、产品、门店、加盟、培训与历史伙伴、养护知识、咨询。门店图片为文档中的空间设计资料，有明确标签。科研、服务、创始人、培训与产品采用真实旧站图片，未生成品牌人物或护理效果图。

产品支持鼠标、触摸和键盘方向键切换；图片可放大；详情弹窗支持焦点限制与 Escape 关闭；手机菜单支持辅助技术；表单标签、隐私同意、错误和成功状态可读取。页面适配减少动态效果的偏好，不加载外部字体。

验证包括 320、390、768、1440px 布局、真实业务操作及 WCAG 2/2.1/2.2 A/AA 自动规则。验证结果不构成国际认证。
